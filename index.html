Knowledge Base & Support

Frequently Asked Questions

Everything you need to know about the Chameleon Engine, custom hex generation, Gemini AI vision, and token exports.

How does the Living Chameleon UI re-theme the entire website?
The studio injects active palette swatches directly into native CSS Custom Properties (--c-node-0 through --c-node-4, background luminance, and typography). The animated mesh aurora, glass cards, buttons, badges, and borders immediately inherit these tokens via CSS cascades with 0ms reload.
Can I generate a complete palette from my own custom color or HEX code?
Yes! In the Custom Color Studio above, enter any 6-digit hex code (e.g. #4f46e5) or use the interactive color picker. Click "Generate from Color" and the Chameleon harmonic algorithm computes an optimal 5-shade design system preserving mathematical harmony and high contrast ratios.
How does Gemini Multimodal Vision extract tokens from images?
Upload any moodboard, UI screenshot, or brand photo. Gemini 2.5 Flash analyzes lighting mood and color dominance to return 5 semantic tokens, ideal Google Fonts pairings, and brand aesthetics. If no API key is entered, an onboard HTML5 Canvas client extractor runs instantly offline.
How does Natural Language Prompt-to-Theme work?
Describe your desired brand identity in plain English (e.g., "Cyberpunk neon crypto exchange" or "Minimalist Scandinavian furniture store"). Gemini outputs structured JSON with 5 hex values, typography pairings, and harmony rules that apply instantly across the studio.
Are the WCAG 2.2 contrast ratings certified and accurate?
Yes. The contrast calculator implements the exact W3C WCAG 2.2 relative luminance specification: converting sRGB values to linear luminance and calculating (L1 + 0.05) / (L2 + 0.05). It validates AA (4.5:1) and AAA (7:1) compliance for normal and large text in real time.
How do I export tokens into my production project?
Navigate to the Export Section above. You can switch between Tailwind CSS config (tailwind.config.js), CSS Custom Properties (:root), SCSS variables, or raw JSON tokens. Click "Copy to Clipboard" or "Download" for immediate integration.
